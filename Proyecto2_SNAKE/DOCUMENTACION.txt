1. CÓMO FUNCIONA EL PROYECTO
================================================================================

El proyecto implementa el clásico juego de la serpiente donde:

- El jugador controla una serpiente que se mueve en un tablero
- Objetivo: Comer manzanas para aumentar la puntuación y crecer
- La serpiente crece cada vez que come una manzana
- El juego termina si:
  * La serpiente choca contra las paredes del tablero
  * La serpiente se choca contra sí misma

FLUJO GENERAL:
1. Se inicializa la vista (Pygame), modelo (datos del juego) y controlador
2. El controlador ejecuta un bucle principal que:
   - Captura eventos del teclado (movimiento)
   - Mueve la serpiente según la dirección
   - Valida colisiones
   - Actualiza la puntuación
   - Redibuja la pantalla
3. Cuando hay colisión, se muestra pantalla de Game Over


================================================================================
2. ESTRUCTURA DEL PROYECTO
================================================================================

El proyecto sigue el patrón arquitectónico MVC (Modelo-Vista-Controlador):

Directorio: Proyecto2_SNAKE/
│
├── main.py                  # Punto de entrada del programa
│
├── model/
│   └── model.py            # SnakeModel: Lógica del juego (datos y reglas)
│
├── view/
│   └── view.py             # SnakeView: Renderizado gráfico (Pygame)
│
└── controller/
    └── controller.py       # SnakeController: Orquestador de entrada/salida


COMPONENTES PRINCIPALES:

A) SnakeModel (model/model.py)
   - Almacena: posición de la serpiente, dirección, manzana, puntuación
   - Responsabilidades:
     * Calcular nuevo movimiento de la serpiente
     * Detectar colisiones
     * Generar posiciones aleatorias para las manzanas
     * Actualizar puntuación

B) SnakeView (view/view.py)
   - Usa la librería Pygame para renderizado gráfico
   - Responsabilidades:
     * Dibujar la serpiente, manzana y fondo
     * Mostrar información en pantalla (puntuación, tiempo)
     * Controlar la velocidad de fotogramas (FPS)
     * Mostrar pantalla de Game Over

C) SnakeController (controller/controller.py)
   - Orquestador principal del juego
   - Responsabilidades:
     * Capturar eventos del teclado
     * Coordinar modelo y vista
     * Ejecutar el bucle principal del juego


================================================================================
3. CÓMO SE MUEVEN LOS DATOS
================================================================================

El flujo de datos sigue el patrón MVC:

ENTRADA (Usuario) → CONTROLADOR → MODELO → VISTA (Salida)

DETALLE DEL FLUJO:

1. CAPTURA DE ENTRADA (Controlador)
   - El controlador escucha eventos de teclado (ARRIBA, ABAJO, IZQUIERDA, DERECHA)
   - Actualiza self.model.direction con la nueva dirección
   - Valida que no sea movimiento opuesto (evita que la serpiente se devuelva)

2. ACTUALIZACIÓN DEL MODELO (Controlador → Modelo)
   - Controlador llama a: model.move()
   - El modelo calcula la nueva posición de la cabeza:
     * new_head = (head_x + direction[0], head_y + direction[1])
   - Inserta la nueva cabeza al inicio: snake.insert(0, new_head)

3. LÓGICA DE COLISIÓN Y CRECIMIENTO (Modelo)
   - Si new_head == apple (comió):
     * Genera nueva manzana: spawn_apple()
     * Incrementa puntuación: score += 1
     * La serpiente NO pierde segmento (crece)
   - Si no comió:
     * Elimina último segmento: snake.pop() (mantiene tamaño)
   - Detecta colisiones: collision()
     * Retorna True si colisiona con paredes o ella misma
     * Retorna False si el movimiento es válido

4. ENVÍO DE DATOS A VISTA (Controlador → Vista)
   - Controlador llama a: view.draw(snake, apple, score)
   - Se envían los datos actualizados del modelo

5. RENDERIZADO (Vista)
   - Dibuja el fondo y cuadrícula
   - Dibuja cada segmento de la serpiente
   - Dibuja la manzana
   - Muestra puntuación y tiempo transcurrido
   - Actualiza la pantalla: pygame.display.flip()


ESTRUCTURA DE DATOS PRINCIPALES:

snake (lista de tuplas):
  - [(100, 100), (80, 100), (60, 100)]  # Ejemplo
  - Cada tupla es (x, y) en píxeles
  - Índice 0 = cabeza, resto = cuerpo

direction (tupla):
  - (dx, dy) en píxeles
  - Ejemplo: (20, 0) = movimiento derecha
  - Ejemplo: (0, -20) = movimiento arriba

apple (tupla):
  - (x, y) posición aleatoria alineada a la cuadrícula

score (entero):
  - Número de manzanas comidas


================================================================================
4. CÓMO MUESTRA LOS DATOS
================================================================================

La vista (Pygame) renderiza toda la información visual del juego:

ELEMENTOS VISUALES:

1. FONDO Y CUADRÍCULA
   - Color de fondo: Azul oscuro (15, 15, 60)
   - Cuadrícula sutil: Líneas gris oscuro cada 20 píxeles
   - Propósito: Crear profundidad visual y referencia de movimiento

2. BORDE DEL TABLERO
   - Color: Azul acero (70, 130, 180)
   - Grosor: 4 píxeles
   - Propósito: Delimitar claramente el área de juego

3. SERPIENTE
   - Color interior: Verde brillante (102, 255, 102)
   - Color borde: Verde oscuro (0, 120, 0)
   - Tamaño: 20x20 píxeles (cell_size)
   - Cada segmento tiene efecto 3D con borde interior
   - Propósito: Mostrar claramente el cuerpo y dirección

4. MANZANA
   - Color: Rojo (255, 80, 80)
   - Forma: Rectángulo redondeado (border_radius=6)
   - Destaque: Color más claro en interior (255, 160, 160)
   - Tamaño: 20x20 píxeles
   - Propósito: Destacar el objetivo a comer

5. PANEL DE INFORMACIÓN (arriba)
   - Ubicación: Esquina superior izquierda
   - Fondo: Rectángulo semi-transparente oscuro
   - Información mostrada:
     * "SNAKE" (título)
     * "Score: XXX" (puntuación actual con 3 dígitos)
     * "Time: XXX" (segundos transcurridos con 3 dígitos)
   - Color de texto: Beige claro (240, 240, 180)
   - Fuente: Arial 18px

6. PANTALLA DE GAME OVER
   - Overlay semi-transparente oscuro sobre toda la pantalla
   - Texto grande: "GAME OVER" en rojo
   - Subtexto: "Gracias por jugar. Cierra la ventana para salir."
   - Duración: 2 segundos antes de cerrar

COLORES DEFINIDOS EN view.py:
  - BACKGROUND: (15, 15, 60)      # Azul muy oscuro
  - GRID_COLOR: (30, 30, 80)      # Azul oscuro para cuadrícula
  - SNAKE_COLOR: (102, 255, 102)  # Verde brillante
  - SNAKE_BORDER: (0, 120, 0)     # Verde oscuro
  - APPLE_COLOR: (255, 80, 80)    # Rojo
  - INFO_BG: (10, 10, 30)         # Azul muy oscuro
  - INFO_TEXT: (240, 240, 180)    # Beige claro
  - BORDER_COLOR: (70, 130, 180)  # Azul acero

VELOCIDAD DE ACTUALIZACIÓN:
  - FPS: 10 fotogramas por segundo (controlado por view.tick())
  - pygame.display.flip() actualiza toda la pantalla en cada frame
  - Proporciona animación suave del movimiento


RESUMEN VISUAL:
El juego presenta una interfaz limpia y profesional con:
- Contraste de colores para fácil legibilidad
- Efectos visuales sutiles (bordes, sombras)
- Información clara y concisa
- Respuesta rápida a las acciones del jugador
